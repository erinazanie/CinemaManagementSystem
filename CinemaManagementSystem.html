1. Introduction

The Cinema Management System is an object-oriented software library developed using C# and .NET Windows Forms. The project demonstrates the application of Object-Oriented Programming (OOP) principles by implementing a reusable class library and a demo application.

The system allows users to browse movies, select showtimes, reserve seats, purchase snacks, and generate booking receipts. The project focuses on clean software design through encapsulation, inheritance, abstraction, interfaces, and polymorphism.

2. System Overview

The Cinema Management System consists of two main components:

  • CinemaManagementLibrary – Contains all business logic and reusable classes.
  • CinemaManagementDemo – A Windows Forms application demonstrating how the library is used.

The system allows customers to:

  • Browse available movies
  • Select showtimes
  • Choose seats
  • Purchase snacks
  • Generate digital tickets

The demo application interacts with the library to perform booking operations while maintaining a clear separation between the user interface and business logic.

4. OOP Concepts Used

Concept Implementation Detail
Encapsulation Class properties and methods keep data organized and controlled
Inheritance ComingSoonMovie extends the Movie class. Moreover, Snack and Ticket classes extend the Item class because a Snack is an Item.
Polymorphism Different ticket types calculate prices using overridden methods that implement different pricing strategies.
Abstraction Each class represents a real-world concept in a simple and clear way.
Composition Booking contains objects such as Customer, ShowTime, Ticket, and Snack.
Overloading We implemented two Hall constructors allowing to instantiate halls with or without a list of seats and add them later.

8. How to Use the Library

The CinemaManagementLibrary project can be reused in other C# applications by adding it as a project reference or referencing the compiled class library (.dll).

Import the library into your project using: 

using CinemaManagementLibrary;

The library provides reusable classes for managing different aspects of a cinema booking system, including:

  • Movie and ComingSoonMovie for managing movie information.
  • Customer and Booking for handling customer bookings.
  • ShowTime, Hall, Seat, and Ticket for scheduling and seat management.
  • Snack and Item for food and beverage purchases.
  • MovieRepository for loading and saving movie data.

These classes can be instantiated and combined to develop custom cinema-related applications or to extend the functionality of the demo application included in this project.
